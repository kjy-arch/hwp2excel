# HWP2Excel

한글(HWP/HWPX) 파일의 표를 엑셀(xlsx) 시트로 변환하는 Windows GUI 프로그램. 표 하나가 시트 하나가 된다.

## 사용법

```bash
pip install -r requirements.txt
python hwp2excel.py
```

1. HWP/HWPX 파일 선택 (저장 위치는 자동으로 `<원본이름>_표변환.xlsx`)
2. 파싱 방식 선택
   - **한글 프로그램 연동 (권장)** — 한글(HWP) 프로그램이 설치된 경우. COM 자동화로 표를 읽는다.
   - **직접 파싱 (한글 미설치)** — HWP 바이너리를 직접 파싱한다.
3. 변환할 페이지 선택 (기본값 전체)
4. 변환 시작

### 포맷별 처리 방식

| 파일 | 처리 |
| --- | --- |
| `.hwpx` | ZIP+XML 직접 파싱 (파싱 방식 선택과 무관, 한글 설치 불필요) |
| `.hwp` + 한글 연동 | 한글로 임시 HWPX 저장 후 XML 파싱 (실패 시 COM 셀 순회) |
| `.hwp` + 직접 파싱 | OLE 레코드 파싱 (HWPTAG_TABLE/LIST_HEADER/PARA_TEXT) |

### 셀 병합

한글의 병합 셀은 엑셀에서도 같은 범위로 병합된다. 값은 좌상단 셀에 들어가고,
병합 범위는 HWPX의 `cellSpan`(colSpan/rowSpan) 또는 OLE `LIST_HEADER`의
열/행 병합 개수(페이로드 오프셋 12/14)에서 읽는다.

첫 행 셀이 아래로 병합된 만큼을 제목 행 묶음으로 보고 굵게·음영·가운데 정렬한다
(예: 2줄짜리 제목 행). 단, 병합이 표 전체 높이를 덮으면 도형용 표로 보고 첫 행만 제목 처리한다.

### 시트 이름

`25_1-1-3. 병역준비역 등 자원 현황 - 청별` 처럼 **쪽 번호 + 표 제목**을 쓴다.

제목은 표 앞 문단에서 찾는다. 통계 문서는 표 바로 위가 "자료출처：…" 같은 주석이고
그 위가 번호 붙은 제목(`1-1-3. …`)인 경우가 많아서, 주석 줄(`자료출처`·`출처`·`주 :`·
`※`·`(단위`)을 걷어낸 뒤 번호 붙은 줄을 우선 고른다. HWPX에 표 캡션(`hp:caption`)이
있는 문서는 드물어 캡션은 쓰지 않는다.

앞머리는 쪽 번호이되, 쪽을 모르면(직접 파싱) 표 번호를 쓴다 — `표009_자원 현황`.
제목을 못 찾으면 예전처럼 `표009`. 엑셀 제약에 맞춰 31자로 자르고(`…`),
금지문자 `[ ] : * ? / \`는 공백으로 바꾸며, 이름이 겹치면 `_2`를 붙인다.

### 변환할 페이지

기본값은 전체다. `○ ㅁ ~ ㅁ`에 쪽 번호를 넣으면 그 범위에서 **시작하는** 표만 뽑는다.
두 쪽에 걸친 표는 시작하는 쪽으로 친다. 표 번호는 문서 전체 기준을 유지하므로
25~27쪽만 변환해도 시트 이름은 `표009`, `표010`, `표011`이 된다.

쪽 번호는 한글이 레이아웃을 계산해야 알 수 있어서 **한글 연동 방식에서만** 지원한다
(`KeyIndicator()`의 쪽 값). `직접 파싱`을 고르면 이 줄은 비활성화된다.
`.hwpx`는 전체 변환이면 한글 없이 XML만 읽고, 페이지를 지정할 때만 한글을 거친다.

### 알려진 제한

- 한글 연동(COM) 방식은 보안 승인 창이 뜰 수 있다("접근 허용" 선택). 배포용 보안 모듈(FilePathCheckerModule)이 레지스트리에 등록된 환경에서는 뜨지 않는다.
- 셀 안의 중첩 표는 별도 표로도 추출되고, 바깥 셀 텍스트에도 섞여 들어갈 수 있다.
- COM 셀 순회로 되돌아간 경우(한글이 HWPX 저장을 못 할 때)에는 병합 정보가 없다.

## exe 빌드

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean HWP2Excel.spec
```

spec을 써야 `icon.ico`가 exe 아이콘으로 박히고 번들에도 들어간다(창·작업표시줄 아이콘용).
`dist/HWP2Excel.exe` 하나만 배포하면 된다.

## 이력

이 소스는 원본 `.py`가 유실된 상태에서 배포본 `HWP2Excel.exe`(PyInstaller, Python 3.14)의 바이트코드를 디스어셈블하여 복원한 것이다. 최초 커밋이 복원된 원본이며, 이후 커밋에서 다음 버그를 수정했다.

- `.hwpx` 미지원 (COM은 포맷 `"HWP"` 고정 + `Open()` 결과 미확인 → 조용히 "표 없음", 직접 파싱은 OLE 전용이라 실패) → hwpx ZIP+XML 파서 추가, 확장자 기반 자동 라우팅
- OLE 파서가 존재하지 않는 스트림 이름(`Section0001`, 실제는 `Section0`)을 조회해 항상 표 0개 반환
- OLE 파서 태그 오류: `HWPTAG_TABLE`은 77(76은 SHAPE_COMPONENT), 행/열 수는 페이로드 오프셋 4/6
- 셀 텍스트를 문단 수 기반으로 세던 것을 LIST_HEADER의 셀 주소(오프셋 8/10) 기반 그리드 배치로 교체 (병합 셀 대응)
- COM 셀 읽기: 존재하지 않는 `ctrl.GetCell()` API 대신 셀 순회(`ShapeObjTableSelCell`/`TableRightCell`) + `InitScan` 텍스트 스캔으로 교체
